# Icons

Feature and project tiles use inline SVG icons from [Lucide](https://lucide.dev/),
pinned to version 1.28.0. Brand icons, including GitHub, continue to come from
Font Awesome through the Minimal Mistakes theme.

The local semantic names map to Lucide icons as follows:

| Local name | Lucide icon |
| --- | --- |
| `modules` | `boxes` |
| `shield` | `shield-check` |
| `boundaries` | `network` |
| `branch` | `git-branch` |
| `route` | `route` |
| `fluid` | `waves-horizontal` |
| `values` | `shapes` |
| `book` | `book-open` |
| `terminal` | `terminal` |
| `storage` | `hard-drive` |
| `desktop` | `monitor` |
| `lock` | `lock-keyhole` |
| `sitemap` | `network` |
| `vial` | `vial` |
| `key` | `key-round` |
| `asterisk` | `asterisk` |
| `matrix` | `grid-3x3` |
| `note` | `notebook-text` |
| `resume` | `file-user` |
| `exhaustive` | `grid-2x2-check` |

All existing icons had an appropriate Lucide equivalent, so no custom SVGs are
currently retained. In particular, `waves-horizontal` preserves the distinctive
three-wave design used by the Fluid project. If a future concept lacks a strong
Lucide match, keep the custom icon and list it here for design review.

Lucide license notices are recorded in `THIRD_PARTY_NOTICES.md`.
